# Api-Moketto
A program that allows you to mock any API endpoint for frontend development, based on NodeJS.

## Features
- **Routes**: any method and path, with a fixed or template response, custom status and headers, a delay and a random failure rate
- **Resources**: full CRUD collections with filtering, sorting and pagination
- **Admin UI** at `/admin`: create and edit everything, send test requests, and watch a live request log
- **Hot reload**
- **CORS on by default**
- **Import**: Import files like a Java/Hibernate entity to automatically generate endpoints.
